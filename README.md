# Portfolio Website

A professional portfolio website built with PHP to showcase skills, projects, and experience.

## Features

- Responsive design with mobile-friendly navigation
- Separate sections for profile, experience, projects, and skills
- Clean and modern UI
- Error handling for a smooth user experience

## Structure

- `index.php` - Main entry point
- `pages/` - Content sections (profile, experience, projects, courses-skills)
- `includes/` - Reusable components (header, navigation, footer)
- `css/` - Styling
- `images/` - Portfolio images and assets

## Setup

1. Clone the repository
2. Upload to a PHP-compatible web server
3. Access via your domain or localhost
